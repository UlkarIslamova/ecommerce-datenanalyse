# E-Commerce Datenanalyse: Logistik, Zufriedenheit und Kundenbindung

**Projekt-Status: 🟢 Aktiv (Work in Progress)**

Dieses Projekt ist eine explorative Datenanalyse (EDA) basierend auf echten E-Commerce-Daten. Das übergeordnete Ziel ist es, die geschäftskritische Kausalkette zu untersuchen: Wie beeinflussen Logistikprobleme die Zufriedenheit und wann führen sie zum direkten Kundenverlust (Churn)?

Das Projekt wird agil und iterativ in aufeinander aufbauenden Phasen entwickelt:

* [x] **Phase 1: Das Fundament (Abgeschlossen)**
  Analyse der direkten Korrelation zwischen realer Lieferzeit und den abgegebenen Sterne-Bewertungen der Kunden.
* [ ] **Phase 2: Die Kundenbindung (In Arbeit)**
  Untersuchung der Wiederholungskäufer-Rate in Abhängigkeit der Erstbewertung (Verbindung zwischen Unzufriedenheit und Abwanderung).
* [ ] **Phase 3: Der Business-Impact (Geplant/Evaluation)**
  Versuch der Quantifizierung des finanziellen Risikos durch langsame Logistik-Ketten (Abhängig von der Tiefe der vorliegenden Daten).
